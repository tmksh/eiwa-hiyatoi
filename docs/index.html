修繕内容

以下の機能を修繕・提供いたします。

A. 本システム基盤修繕

  • ダッシュボード（日次計算ステータス・未処理アラート・統計サマリー）
  • 勤怠・労務（作業日誌取込み・承認フロー・雇用区分管理・休暇管理）
  • 賃金・支払（全銀協FBデータ自動生成・金種表自動計算・給与明細）
  • 給与計算ロジック（196テーブル計算ロジック移植・さかのぼり再計算・週40h割増等）
  • 集計・分析・データ出力（個別集計・燃費集計・稼働分析・各種PDF自動生成）
  • データ移行・検証（既存AccessDB 196テーブルからの全データ移行・整合性検証）
  • システム設定（基本管理・通知・ユーザー・バックアップ管理）
  • 全社共通マスター設定（日雇い賃金管理システムに係る部分）
  • DB設計・構築・連携（マルチテナント対応スキーマ・マイグレーション・DB管理）
  • セキュリティ対策（脆弱性対策・データ暗号化・監査ログ）
  • 動作テスト・品質担保（総合動作テスト・データ出力テスト）
  • CI/CD構築（自動デプロイ・ステージング環境）
  • 環境構築（本番環境セットアップ・ドメイン設定）
  • マスタデータ登録（日雇い賃金管理システムに係る項目の初期設定）
  • 導入サポート一式（管理者向け・ユーザー向け操作案内）
  • ドキュメント作成（仕様書・マニュアル・SaaS運営ガイド）

B. SaaS基盤修繕

  • マルチテナント対応（テナントごとのデータ完全分離・Row Level Security）
  • 認証・認可システム（Supabase Auth連携・招待制ユーザー登録・SSO対応準備）
  • ロール・権限管理（管理者/経理担当/閲覧者等の段階別権限・テナント別権限設定）
  • テナント管理画面（契約企業の登録・編集・停止・利用状況確認）
  • 課金・サブスク管理（月額プラン管理・利用量トラッキング・請求書自動生成）
  • SaaS運営ダッシュボード（全テナントの統計・利用状況・収益分析・アラート通知）
  • オンボーディング（新規テナント初期設定ウィザード・マスタデータインポート）
